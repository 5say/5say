一、什么是树

1.1 树的定义与相关概念

🌱 树（Tree） 是一种非线性数据结构，是一种“分层”的结构，最常见的是“二叉树”。

📌 树的基本术语：

  • 根节点（root）：树的起点
  • 子节点（children）：根的下一级
  • 叶子节点（leaf）：没有子节点的节点
  • 高度（height）：从节点到叶子的最长路径
  • 深度（depth）：从根到该节点的路径长度
  • 二叉树：每个节点最多有两个子节点（左/右）
  • 前序遍历：根 -> 左 -> 右
  • 中序遍历：左 -> 根 -> 右
  • 后序遍历：左 -> 右 -> 根
  • 层序遍历：一层一层从上往下

✅ 画个图（文字版）： 

        A
       / \
      B   C
     / \   \
    D   E   F
  • 根：A
  • A 的子节点：B, C
  • 叶子节点：D, E, F
  • A 高度 = 3（从 A→D 路径有3层）

1.2 怎么使用Java代码定义一个树 

public class TreeNode {
    int val;
    TreeNode left,right;
}

1.3 树的初始化

1.3.1 手动初始化 

public void testInit(){
    TreeNode root = new TreeNode(1);
    root.left = new TreeNode(2);
    root.right = new TreeNode(3);
    root.left.left = new TreeNode(4);
    root.left.right = new TreeNode(5);
}

1.3.2 通过数组初始化（完全二叉树） 

public void testBuildTree(){
    Integer[] values = {1, 2, 3, 4, 5};
    TreeNode root = buildTree(values, 0);
    System.out.print("层序遍历:");
    levelOrder(root);
}

public static TreeNode  buildTree(Integer[] arr,int index){
    if (index >= arr.length || arr[index] == null) {
        return null;
    }

    TreeNode node = new TreeNode(arr[index]);
    node.left = buildTree(arr, 2 * index + 1);
    node.right = buildTree(arr, 2 * index + 2);
    return node;
}

二、二叉树

二叉树是最常见的树状结构，通过二叉树我们可以找到许多树状结构的特点

2.1 二叉树的定义 

public class TreeNode {
    int val;
    TreeNode left,right;
}

2.2 二叉树遍历节点

2.2.1 前序遍历 

public static void preOrder(TreeNode root) {
    if (root == null) return;
    System.out.print(root.val + " ");
    preOrder(root.left);
    preOrder(root.right);
}

2.2.2 中序遍历 

public static void inOrder(TreeNode root) {
    if (root == null) return;
    inOrder(root.left);
    System.out.print(root.val + " ");
    inOrder(root.right);
}

2.2.3 后序遍历 

public static void postOrder(TreeNode root) {
    if (root == null) return;
    postOrder(root.left);
    postOrder(root.right);
    System.out.print(root.val + " ");
}

2.2.4 层序遍历（使用队列，BFS） 

public static void levelOrder(TreeNode root){
    if (root == null) return;
    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);

    while (!queue.isEmpty()) {
        TreeNode node = queue.poll();
        System.out.print(node.val + " ");

        if (node.left != null) queue.offer(node.left);
        if (node.right != null) queue.offer(node.right);
    }
}

三、二叉查找树（BST）

3.1 什么是 BST（二叉查找树）？

定义： 二叉查找树（Binary Search Tree）是一种特殊的二叉树，它满足以下性质：

  • 对于任意一个节点 node：
    • 所有左子树节点的值 < node.val
    • 所有右子树节点的值 > node.val

👉 这保证了 中序遍历结果是一个升序数组！

四、AVL树（Adelson-Velsky and Landis Tree）

4.1 什么是 AVL 树？

AVL树（Adelson-Velsky and Landis Tree） 是最早的自平衡二叉查找树，由苏联科学家 Adelson-Velsky 和 Landis 在1962年提出。

核心目标：保持 BST 的高度平衡，防止退化成链表。

AVL树的平衡规则：

每个节点维护一个属性：平衡因子（Balance Factor）

平衡因子 = 左子树高度 - 右子树高度
  • 平衡因子 ∈ {-1, 0, +1} ：说明节点是“平衡”的
  • 超过这个范围（如 +2 或 -2）→ 失衡 → 需要旋转来恢复平衡

4.2 AVL树的4种旋转操作

AVL 树使用旋转（rotation）来重新调整结构，保持平衡。

4.2.1 LL（右旋）—— 插入到左子树的左侧 

      A               B
     /               / \
    B      →        C   A
   /
  C

4.2.2 RR（左旋）—— 插入到右子树的右侧 

    A                  B
     \                / \
      B     →        A   C
       \
        C

4.2.3 LR（先左旋后右旋）—— 插入到左子树的右侧 

      A              A               C
     /              /               / \
    B     →        C      →        B   A
     \            /
      C          B

4.2.4 RL（先右旋后左旋）—— 插入到右子树的左侧 

    A                A                  C
     \                \                / \
      B     →          C     →        A   B
     /                  \
    C                    B

五、红黑树

红黑树是一种带有颜色属性（红或黑）的自平衡二叉查找树（BST），通过一组规则来控制树的平衡，确保最坏情况下操作的时间复杂度是 O(log n)。

Java 的 TreeMap / TreeSet，C++ STL 的 map/set，底层都是红黑树。

5.1 红黑树的 5 条性质（核心）

红黑树在节点上增加了“红/黑”颜色标记，并遵循下面 5 个性质：

  1. 每个节点是红色或黑色
  2. 根节点是黑色
  3. 所有叶子节点（NIL）是黑色（可以省略，但概念中存在）
  4. 如果一个节点是红色，则它的子节点必须是黑色（即 不能连续两个红节点）
  5. 从任意节点出发，到其所有叶子节点的路径上，黑色节点数量相等（称为“黑高”一致）

这些规则共同确保红黑树的最长路径 ≤ 2×最短路径，从而避免极端不平衡。
