🔧 一、部署前的准备

1.1 硬件要求

模型版本 显存需求（GPU） 内存需求（RAM） 硬盘空间 推荐显卡型号
1.5B ≥1 GB ≥8 GB 4 GB RTX 3050
7B/8B ≥4–8 GB ≥16 GB 12–20 GB RTX 4060 / AMD RX 6600
14B ≥8 GB ≥32 GB 40 GB RTX 4080 SUPER
32B/70B ≥16–24 GB ≥64 GB 65+ GB RTX 4090 / RTX 5090 D

💡 说明：

  • 若无独立显卡，可用 CPU 模式运行（需 ≥16GB 内存，但速度较慢）158。
  • 模型越大效果越好，但资源消耗显著增加。

⚙️ 二、部署方法（推荐 Ollama）

2.1 安装 Ollama 框架

  • Windows：

    • 官网下载安装包 Ollama 官网 → 双击安装（默认路径 C:\）

    • 自定义安装路径（可选）：

      bash

      OllamaSetup.exe /dir="D:\Program Files\Ollama"

  • Mac：

    bash

    brew install ollama  # 或官网下载 .pkg 安装

2.2 下载 DeepSeek 模型

bash

# 根据配置选择模型（示例：7B 版）
ollama run deepseek-r1:7b

支持版本：1.5b（低配）、7b/8b（均衡）、14b/32b（高性能）169。

2.3 启动模型交互

bash

ollama run deepseek-r1:7b  # 命令行输入问题，实时获取回答

退出按 Ctrl+C 或输入 /exit 15。

2.4 修改模型存储路径（可选）

  • 设置环境变量 OLLAMA_MODELS 指向自定义目录（如 D:\OllamaAI），避免占用 C 盘空间19。

🖥️ 三、可视化界面配置（可选）

3.1 Chatbox（简单易用）

  • 下载 Chatbox → 安装后配置：
    • API 类型：Ollama API
    • 接口地址：http://localhost:11434
    • 模型名称：deepseek-r1:7b（与下载版本一致）59。

3.2 Open WebUI（Docker 支持）

bash

# 拉取并运行 Open WebUI
docker run -d -p 3000:8080 -v open-webui:/app/backend/data ghcr.io/open-webui/open-webui:main
  • 访问 http://localhost:3000 → 设置中连接 Ollama 地址 http://host.docker.internal:1143468。

🚀 四、进阶部署方案

4.1 企业级部署（Docker + Nginx）

  • 适用场景：需域名访问、HTTPS 加密、高并发。

  • 步骤：

    1. 通过 Docker 部署 Ollama 服务：

      bash

      docker run -d -p 11434:11434 --name ollama ollama/ollama

    2. 使用 Nginx 配置反向代理至 http://localhost:11434，并启用 HTTPS 8。

4.2 开发者方案（vLLM / PyTorch）

  • vLLM（高性能推理）：

    bash

    pip install vllm
vllm serve <模型路径> --quantization gptq --dtype half

  • PyTorch 原生部署（代码控制灵活）：

    python

    from modelscope import AutoModelForCausalLM
model = AutoModelForCausalLM.from_pretrained("deepseek-r1", device_map="cuda")

适合熟悉 Python 的开发者3。

⚠️ 五、常见问题解决

问题 解决方案
模型下载失败 检查网络，或切换镜像源（如魔搭社区）1
显存/内存不足 换用小模型（如 7B→1.5B），关闭占用显存的程序，或减少 max-model-len 35
端口冲突（11434） 终止占用进程：taskkill /PID <进程ID> /F（Windows）9
响应速度慢 启用 GPU 加速：ollama run --gpu deepseek-r1:7b，或启用量化（如 q4_K_M 后缀模型）310
