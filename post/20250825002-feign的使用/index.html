编程中间件面试

FeignSpring Cloud 中非常核心的服务调用组件。 我会从 它是什么 → 怎么用 → 常见配置 → 实现原理 → 常用注解和方法 给你讲清楚。

🔹 一、Feign 是什么

Feign 是一个 声明式 HTTP 客户端，最早由 Netflix 开源，后来被 Spring Cloud 集成（现在常用的是 Spring Cloud OpenFeign）。

👉 用一句话总结： Feign = RestTemplate + Ribbon/LoadBalancer + 动态代理

它的好处是：你只需要写接口，不用自己拼 URL、写 RestTemplate 请求，调用别的微服务就像调用本地方法一样。

🔹 二、Feign 怎么用

1. 引入依赖 

<dependency>
  <groupId>org.springframework.cloud</groupId>
  <artifactId>spring-cloud-starter-openfeign</artifactId>
</dependency>

2. 启动类开启 Feign 

@SpringBootApplication
@EnableFeignClients  // 开启 Feign 客户端功能
public class ConsumerApplication {
    public static void main(String[] args) {
        SpringApplication.run(ConsumerApplication.class, args);
    }
}

3. 定义 Feign 接口 

@FeignClient(name = "service-provider")  // 服务名（注册到 Nacos/Eureka 的名字）
public interface ProviderClient {

    @GetMapping("/hello")
    String hello();

    @PostMapping("/user")
    User addUser(@RequestBody User user);
}

4. 在业务中调用 

@RestController
public class TestController {
    @Autowired
    private ProviderClient providerClient;

    @GetMapping("/call")
    public String call() {
        return providerClient.hello(); // 就像调用本地方法一样
    }
}

🔹 三、常用配置（application.yml） 

feign:
  client:
    config:
      default:              # 全局配置
        connectTimeout: 5000
        readTimeout: 5000
        loggerLevel: FULL   # 日志级别: NONE, BASIC, HEADERS, FULL
      service-provider:     # 针对具体服务配置
        connectTimeout: 2000
        readTimeout: 2000
  compression:
    request:
      enabled: true         # 开启请求压缩
    response:
      enabled: true         # 开启响应压缩

🔹 四、Feign 实现原理

Feign 底层主要用到：

  1. 动态代理：Spring 在启动时会为接口生成代理对象，调用方法时转为 HTTP 请求。
  2. 服务发现：结合 Ribbon（旧）或 Spring Cloud LoadBalancer（新）来做负载均衡。
  3. 请求发送：默认基于 HttpURLConnection，也可以换成 OkHttp 或 Apache HttpClient。
  4. 契约（Contract）：解析注解（@GetMapping, @PostMapping）来生成请求。
  5. 拦截器（Interceptor）：支持全局或局部拦截器（如日志、鉴权）。

👉 流程大致是：

你调用接口方法 → Feign 动态代理拦截 → 根据注解组装 HTTP 请求 → 
LoadBalancer 获取服务地址 → 发送请求 → 结果反序列化 → 返回对象

🔹 五、常用注解

  1. @FeignClient

    • 标记一个接口为 Feign 客户端。
    @FeignClient(name = "service-provider", path = "/api", fallback = ProviderFallback.class)
public interface ProviderClient {}

  2. @GetMapping / @PostMapping

    • 定义 HTTP 请求方式和路径。

  3. @RequestParam

    • GET 请求传参。
    @GetMapping("/user")
User getUser(@RequestParam("id") Long id);

  4. @PathVariable

    • RESTful 风格路径参数。
    @GetMapping("/user/{id}")
User getUser(@PathVariable("id") Long id);

  5. @RequestBody

    • POST 请求 JSON 对象。
    @PostMapping("/user")
User addUser(@RequestBody User user);

  6. fallback / fallbackFactory

    • 服务降级处理。
    @FeignClient(name="service-provider", fallback=ProviderFallback.class)
public interface ProviderClient {}

🔹 六、编程中常用的方法

其实 Feign 不直接暴露方法，它就是通过接口调用。但有一些常见用法：

  1. 调用远程服务（最常用） 

    providerClient.getUser(1L);

  2. 日志调试 

    @Bean
Logger.Level feignLoggerLevel() {
    return Logger.Level.FULL;
}

  3. 自定义拦截器（例如加 token） 

    @Configuration
public class FeignConfig implements RequestInterceptor {
    @Override
    public void apply(RequestTemplate template) {
        template.header("Authorization", "Bearer " + getToken());
    }
}

  4. 切换底层 HTTP 客户端 

    <dependency>
    <groupId>io.github.openfeign</groupId>
    <artifactId>feign-okhttp</artifactId>
</dependency>

🔹 七、总结

  • Feign 是声明式 HTTP 客户端，帮我们简化服务间调用。
  • 核心注解：@FeignClient、@GetMapping、@PostMapping、@RequestParam、@PathVariable、@RequestBody、fallback。
  • 常用配置：超时时间、日志、压缩、负载均衡。
  • 扩展能力：拦截器、切换 HTTP 客户端、结合 Sentinel 做熔断。

👉 一句话：Feign 让你调用远程服务像调用本地方法一样简单。
